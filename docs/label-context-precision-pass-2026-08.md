# Label context precision pass — 2026-08

The catalog now carries bespoke caution notes for the remaining public labels
that had a definition but no usage or boundary note. These are not generic
disclaimers: each note identifies a likely conflation or a design distinction.

Covered families include mutualism, council communism, agorism, ecosocialism,
degrowth, deep ecology, Maoism, Trotskyism, guild socialism, liquid democracy,
utopian socialism, libertarian municipalism, anarcho-syndicalism, platformism,
Georgism, bleeding-heart libertarianism, constitutional monarchism,
fundamentalist theocracy, universal basic income, and the social-investment
state. The two remaining labels without notes are retired compatibility entries
(`national-traditionalist` and `civil-libertarian-cosmopolitan`) and are not in
the public catalog.

The notes clarify boundaries without turning a specialist or context entry into
a scored primary identity. Specialist measurement remains provisional and
context entries remain non-scored.
