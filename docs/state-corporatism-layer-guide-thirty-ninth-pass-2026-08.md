# State corporatism layer guide

Date: 2026-08-11

## Scope

This focused editorial pass adds the missing descriptive layer summary for
`corporatism`, whose catalog label is specifically **State Corporatism**. Its
direct term definition and prescriptive summary already described state-led
functional representation, but the descriptive layer did not distinguish the
authoritarian model from societal or neo-corporatist bargaining. No centroids,
axis weights, question prompts, or scoring behavior changed.

## Layer decision

**State Corporatism** now describes the expectation that recognized
occupational bodies under state direction can mediate class and sectoral
conflict more effectively than pluralist party competition. It also makes the
comparative distinction that scholarship draws between authoritarian state
corporatism and autonomous societal or neo-corporatism; the catalog does not
treat democratic interest-group bargaining as the same system.

This is a descriptive account of the state-corporatist model, not an
endorsement of its claims or a claim that corporatist arrangements have one
uniform institutional effect.

## Source basis

- Ming-Sho Ho, “State Corporatism,” _The Wiley Blackwell Encyclopedia of Race,
  Ethnicity, and Nationalism_ (2015), on state corporatism as authoritarian
  interest organization in which the government creates exclusive associations
  claiming representative authority:
  https://doi.org/10.1002/9781118663202.wberen366
- Philippe C. Schmitter’s state/societal distinction as summarized in
  comparative political research, distinguishing organizations directed from
  above from autonomous associations and negotiated democratic bargaining:
  https://tidsskrift.dk/scandinavian_political_studies/article/download/32323/30095?inline=1
- The catalog’s existing scope note, which keeps State Corporatism separate
  from societal or neo-corporatism in democratic welfare states, remains the
  governing taxonomy for this label.
