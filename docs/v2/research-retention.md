# v2 Research Retention

Phase 13 defines an append-only local/staging store for protocol and integration testing. It does not authorize production fielding or establish a final institutional retention period. Any staging dataset must be deleted or isolated at the end of the test window.

The production retention period, deletion workflow, withdrawal workflow, access roles, and legal review remain deployment gates. The Worker does not expose a public read endpoint. Export is an operator-controlled, redacted analysis operation.
