# v2 Research Protocol

Status: Phase 13 infrastructure contract, research-only, not fielding approval.

The optional research submission is an explicit-consent record of the v2 response state for the current assessment. It is not an assessment result and it is not an input to scoring. The current protocol collects only:

- raw core and explicitly requested specialist response states;
- the exact response and content/scoring/result version bindings;
- consent version, UTC consent timestamp, purpose, and no-linkage declaration;
- an opaque submission ID generated by the client.

The protocol intentionally does not collect names, email addresses, accounts, IP addresses, device fingerprints, session identifiers, private-save payloads, share tokens, self-labels, demographics, predicted labels, diagnostics, or result projections. A future task that needs any of those fields requires a separate reviewed protocol version.

`research-v2.phase13.1`, `research-protocol-v2.phase13.1`, and `consent-v2.phase13.1` are exact acceptance values. The Worker accepts only the current v2 content fingerprint and version bindings. Unknown versions fail closed.

Research is disabled in production. Local or test collection requires an explicit non-production flag and an exact origin allowlist.
