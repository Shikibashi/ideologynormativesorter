# v2 modifier semantics

Modifiers are a separate result layer over the core `ConstructAssessment`.
Core-construct modifiers use their explicit direct indicators, evidence gates,
and fit thresholds. Focused-follow-up and catalog-only records are retained as
content metadata but are not silently promoted into ordinary core scoring.

Phase 6 owns modifier matching. Phase 7 specialist module scoring does not
consume modifier results or primary profile ranks.
