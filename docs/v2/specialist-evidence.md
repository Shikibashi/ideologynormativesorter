# v2 specialist evidence

Specialist evidence is scoped to a module's declared items and local
constructs. The authoritative Phase 7 module result records answered, missing,
skipped, abstained, and refused counts; item and answered-weight coverage;
construct coverage; activation thresholds; and closed insufficient-evidence
reasons.

Phase 8 exposes those records unchanged and derives only references to local
construct diagnostics and profile comparisons. An inactive or insufficient
module is not described as a negative ideological result.
